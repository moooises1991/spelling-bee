# Colmena Spelling Bee

Juego para practicar las 672 palabras del Spelling Bee de 4.º grado: audio grabado de cada palabra, definición y oración; 8 niveles con examen perfecto; reporte de avance; y modo micrófono para deletrear en voz alta.

- `site/` es la página publicada con GitHub Pages.
- El modelo de voz (Vosk small en-us, Apache 2.0) se descarga al publicar; ver `.github/workflows/pages.yml`.
- El progreso se guarda en el navegador del dispositivo donde se juega.
